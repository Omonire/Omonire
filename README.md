## 🏗️ Omonire Ecosystem

The Omonire Ecosystem is a collection of reusable software infrastructure and developer-facing systems.

### ⚙️ Omonire Backend

A standalone **Python backend framework and infrastructure project** designed to provide application-level backend capabilities without being fundamentally coupled to Flask.

The long-term direction is framework-independent backend infrastructure that can integrate with different applications and services.

### 🎥 Omonire Video-Conf

A standalone **WebRTC video-conferencing infrastructure** project with a control plane for rooms, participants, permissions, authentication, moderation, and real-time events.

It is paired with **Omonire Media**, a native media-session subsystem for media orchestration and routing.

The integration layer is designed for applications built with **Flask, Django, Node.js, React, HTTP, and WebSocket** technologies.

Engineering targets are approximately **1,000 participants in normal deployments** and an architectural target of approximately **4,000 participants**, subject to infrastructure, network conditions, and media capacity.

### 🧰 Omonire CLI & Developer Tooling

Command-line tools and developer utilities for Omonire projects, automation workflows, and infrastructure.

These tools are being developed incrementally rather than presented as finished public products.

## 🚀 AtendeX Technology

### AtendeX-Grid — *Where Integrity Meets Attendance*

AtendeX-Grid is a **presence-validation system** designed to reduce identity and attendance fraud in academic and institutional environments.

Core engineering areas include:

- **Spatial Validation Engine** — GPS-based proximity validation using Haversine calculations
- **Token-Sync Protocol** — time-bound identity tokens
- **Security Sentinel** — defensive controls including WAF, VPN detection, and brute-force protection
- **Command Center** — administrative control and system governance
- **Audit Ledger** — persistent system history and recovery-oriented records

**Repository:** https://github.com/Omonire/AtendeXportal-University
